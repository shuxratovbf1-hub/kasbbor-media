## Как проходит один запуск

1. Открой `calendar.md`, найди строку на сегодня (Asia/Tashkent). Нет строки или статус не `план` — заверши запуск без публикации.
2. Собери материал. Только реальные данные:
   - вакансии и цифры — с kasbbor.uz или из канала @kasbbor (WebFetch `https://t.me/s/kasbbor`, встроенный браузер, если доступен);
   - цифры рынка — только из открытых источников (Нацкомстат, hh.uz, СМИ) с указанием источника и периода на слайде;
   - не нашёл данных — замени тему на рубрику Maslahat (совет), где цифры не нужны. Никогда не выдумывай вакансии, зарплаты, цифры.
3. Сделай материал по шаблонам из `kit/`:
   - пост / карусель 1080×1350 JPEG: по образцу `kit/launch.html`, рендер `python3 kit/render.py <abs path html> <число слайдов> <папка>`;
   - рилс 1080×1920 mp4, 10–15 с: по образцу `kit/reel_a.html` (график) или `kit/reel_b.html` (шаги), функция `draw(t)`, рендер `python3 kit/render_reel.py <abs path html> <сек> <out.mp4>`; сначала проверь 3–5 кадров (`... out.mp4 1.2 6 11`) и посмотри их;
   - Chrome: `/usr/bin/google-chrome`, шрифт Inter / Inter Display (Unbounded недоступен).
4. Положи файлы в папку `ГГГГ-ММ-ДД-<slug>/` этого репозитория, закоммить и запушь в `main`.
5. Опубликуй через Windsor `execute_action`: карусель — `create_carousel_post` (`image_urls`), рилс — `create_video_post` (`video_url`, `share_to_feed: true`), один пост — `create_image_post`. Ссылки: `https://raw.githubusercontent.com/shuxratovbf1-hub/kasbbor-media/main/<путь>`.
6. Отметь в `calendar.md` статус `опубликовано` + media id, закоммить. Коротко сообщи Бекзоду результат (на русском).
7. Ошибка публикации — не повторяй больше одного раза; статус `ошибка: <причина>`, сообщи Бекзоду причину.

Не отвечай на комментарии и не пиши в директ от имени аккаунта — это только с согласия Бекзода.

## Бренд

- Цвета: фон #F4F7F6, карточки #FFFFFF, текст #0B1B17, вторичный #5A6B66, главный emerald #087F57, мягкий #E2F6EE, искра coral #FF6A55 (только точки/бейджи, текст на ней — тёмный), работодатель violet #5B3DF5 / #ECE8FF.
- Градиент «Аврора»: `linear-gradient(135deg,#087F57 0%,#12B886 45%,#FF8A6B 100%)` — обложки, рилсы, CTA.
- Логотип: только файлы `kit/logo_*.svg` (dark — на светлом, white — на градиенте, ondark — на тёмном). Не перенабирать.
- Скругления 24–32 px, мягкая тень, без толстых рамок. Эмодзи в подписи — не больше 4.
- Узбекские oʻ, gʻ — через ʻ (U+02BB).
- Нижние ~300 px рилса закрывает интерфейс Instagram — важный текст туда не ставить.
